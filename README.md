# Personal Portfolio Website

My personal portfolio website showcasing my projects and skills as a Computer Science engineering student.

## Live Preview

Open `index.html` in any browser — no installation needed.

## Sections

- **Hero** — Introduction and call to action
- **About** — Background, skills, and stats
- **Projects** — All my GitHub projects with links
- **Contact** — GitHub and email links

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, CSS Variables)
- No frameworks — pure HTML/CSS
